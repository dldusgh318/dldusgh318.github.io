## 어떤 프로젝트인가요

채용공고를 한곳에서 검색하는 서비스 '직행'의 기업 연계 과제입니다. 한국대학생IT경영학회 KUSITMS에서 5주 동안 기획·디자인·FE·BE가 함께 진행했고, 가입 유도와 온보딩을 통한 개인화 문제를 다뤘습니다.

## 핵심 문제 해결

### 사용자 인터뷰로 시작한 기획

팀원들과 취업·이직 준비자 16명을 인터뷰하고, 성향 테스트에서 가입·온보딩, 맞춤 공고로 이어지는 흐름을 함께 기획했습니다. 백엔드만 맡고 기다리지 않고 매일 회의에 참여해 사용자 흐름, 데이터 조건, 구현 제약을 맞췄습니다.

### 외부 API 호출 제약을 기획과 함께 조율

TMAP API는 호출 비용과 제한이 있어서, 모든 공고에 통근 시간을 계산할 수 없었습니다. 이 제약을 팀에 공유하고, **온보딩 조건에 맞는 후보 공고를 먼저 만든 뒤 통근 시간을 계산**하도록 순서를 조율해 불필요한 외부 호출을 줄였습니다.

### 맡은 기능

- 카카오 OAuth2 로그인과 JWT Access/Refresh Token 인증
- 마이페이지
- TMAP API 기반 통근 시간 필터 (자동차·대중교통)
- NCP 서버 구축과 배포

> 팀 결과: KUSITMS 기업과제 **공동 1위 최우수상**. 기업 측에서 추후 서비스에 반영할 계획이라고 전해 왔습니다.
